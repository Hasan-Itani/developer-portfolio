## Design and motion requirements
- The interface should feel custom-designed by a high-quality product/design studio, not autogenerated. Prefer visual restraint, striking typography, and highly polished transitions over generic glowing blobs/glass cards.
- Use a consistent motion language (easing, durations, delays). Support reduced-motion, touch, low-power devices, and keyboard navigation.
- In the project narrative, create a compelling sense of **progression** as the user scrolls: e.g. a sticky visual stage with transitions between projects while copy updates alongside it. Avoid large blank pinned areas, broken footer navigation, or scroll traps.
- Implement at least one refined parallax effect, one kinetic text reveal, one scroll-linked project transition, and one timeline progress animation. No autoplay sound, giant canvas, or gratuitous 3D.
- Check 390px mobile, 768px tablet, and 1440px desktop layouts. No horizontal overflow.
